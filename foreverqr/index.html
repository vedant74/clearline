Questions

Is there a QR code generator that doesn’t expire?

Yes — this one. Every code made here is static: your link or text is stored inside the black-and-white pattern. There’s no server in between and no account, so there is nothing that can expire or be switched off.

My QR code stopped working after the free trial. Why?

Most “free” generators make dynamic codes by default. Those codes point to the company’s own short link, which forwards people to your site. When the trial ends, they stop forwarding unless you subscribe. You can’t fix an already-printed dynamic code without their account — but you can make a static replacement here in seconds, for free, and it will never die again.

Is it really free with no signup?

Yes. No account, no email, no watermark, no limit on how many codes you make or how many times they’re scanned. Codes are generated in your browser; we never see what you put in them.

Static vs dynamic QR codes — what’s the difference?

Static: the destination is baked into the code. Free, permanent, private, can’t be edited after printing.
Dynamic: the code holds a short link you can re-point later and can count scans — but it only works while the short-link service keeps running. Ours will be a one-time purchase (coming soon).

Can I put my logo in the middle?

Yes. Upload it under “Style & quality”. We automatically switch to High error correction so the code still scans with part of it covered. Always test-scan before printing.

Which file should I use for printing?

SVG is a vector file — it stays sharp at any size and is best for designers and print shops. PNG at 2048 px is fine for flyers, menus and posters. Keep the code at least 2 cm (about 0.8 in) wide and keep dark-on-light colours with strong contrast.

Can I use the codes commercially?

Yes — menus, packaging, business cards, signage, anything. No attribution needed.

Why doesn’t the scanner open links automatically?

Malicious QR codes (“quishing”) are common. We show you the full address first, highlight the actual domain, and only open it when you tap. No ads next to your result, ever.
