Make a Wi-Fi QR code

How a Wi-Fi QR code works

There is no website or app behind a Wi-Fi code. The login details are written into the code as a short piece of text in a format that phone cameras recognise:

WIFI:T:WPA;S:CafeGuest;P:espresso-2026;;
  • T is the security type: WPA (used for WPA/WPA2 and most mixed WPA2/WPA3 home and office routers), WEP for very old equipment, or nopass for an open network.
  • S is the network name (SSID). It is case-sensitive: CafeGuest and cafeguest are different networks.
  • P is the password. Characters such as ; , : " and \ must be escaped with a backslash. ForeverQR does this for you.
  • H:true is added for hidden networks that don’t broadcast their name.

The format began in the open-source ZXing barcode project and is now referenced by the Wi-Fi Alliance: the WIFI: URI scheme is registered with IANA, pointing to the WPA3 specification.

Which phones can scan it?

On iPhone and iPad, the built-in Camera app (or the Code Scanner in Control Center) reads QR codes; for a Wi-Fi code it offers to join the network. Android added Wi-Fi sharing and joining by QR code in Android 10, and most current Android camera apps and Google Lens recognise these codes. Older phones may need a scanner app. Always test with one iPhone and one Android phone before you print.

Step by step

  1. Find the exact network name. Copy it from your router’s admin page or the label on the router, including capitals and spaces.
  2. Open the generator with the button above. Wi-Fi is already selected.
  3. Enter the name and password and choose the security type. Pick “None” only if the network really has no password.
  4. Test it. Point a phone at the preview on your screen. It should offer to join the network by name. Join it to be sure the password is right.
  5. Download. Use “Printable sign” for a 6 × 8 inch card with your caption and the network name, or download the plain PNG/SVG to put into your own design.

Tips before you print

  • Use a guest network. Anyone who photographs the sign has the password. Most routers can run a separate guest network that can’t see your printers, tills or laptops.
  • Changing the password means a new code. The password lives inside the code, so if you change it the old code stops working. This is true of every Wi-Fi QR code, including ones sold as “dynamic”: a phone needs the real password to join, so there is no redirect that could be updated.
  • Size for the distance. A common rule of thumb is a scanning distance of about 10 times the code’s width, with 2 cm (0.8 in) as a practical minimum. A table card read at arm’s length works at 3–4 cm; a sign on the wall read from 2 metres needs about 20 cm.
  • Keep it simple. Dark code on a light background, the default margin, and no glossy laminate if you can help it, because glare is the most common reason a printed code won’t scan.

FAQ

Do Wi-Fi QR codes expire?

No. The network name and password are written into the code itself, so it works for as long as the network and password stay the same. Nothing online is involved.

What happens if I change my Wi-Fi password?

The old code stops working because it still holds the old password. Make a new code with the new password and replace the sign.

Does a Wi-Fi QR code work on iPhone?

Yes. The iPhone Camera app and the Code Scanner in Control Center read Wi-Fi QR codes and offer to join the network. Android 10 and later also support joining Wi-Fi by QR code.

Is it safe to post a Wi-Fi QR code in public?

Treat it like printing the password on the wall, because that is what it is. Use a guest network that is isolated from your business devices.

Can I make a code for a hidden network?

Yes. Tick “Hidden network” in the generator; it adds H:true to the code so phones know to look for a network that doesn’t broadcast its name.
