A QR code is a printed pattern. The pattern can’t expire. What can stop working is the service some codes depend on, and that depends entirely on how the code was made.

Why some codes stop after a trial

Dynamic codes are often the default on sites that offer a free trial. When the trial ends, the provider’s rules decide what happens to the redirect. One widely used provider, QR Code Generator, says in its help centre that dynamic QR codes are deactivated when the free trial ends and point to a service page instead of the original destination, while static codes in the account continue to work. It also says upgrading reactivates them. Other services have their own terms, so check before you print. The point isn’t that dynamic codes are bad; it’s that they are a subscription, and it’s worth knowing that before you put one on 5,000 flyers.

What “never expires” really means

A static code works for as long as what’s inside it does. Every code made on ForeverQR is static, made in your browser, with no account and no server in between, so there is nothing we, or anyone else, could switch off. These things can still break a static code, and they are all in your hands:

  • The web page moves or is deleted, or your domain name lapses.
  • A shared file is replaced with a new file that has a new link.
  • Wi-Fi passwords change (for Wi-Fi codes).
  • The print is too small, too pale, glossy or damaged.

Get “editable” without a subscription

Put an address you control into the code (yourbusiness.com/menu, yourbusiness.com/offer) and change the page behind it whenever you like. If you run a website, you can also make that address a redirect you manage yourself. You get the main benefit of a dynamic code, changing the destination after printing, with no middleman.

How to check whether a code is static

  1. Open the ForeverQR scanner and scan the code with your camera or upload a photo of it. It shows the full content and never opens links by itself.
  2. Look at the highlighted domain. If it’s your own website, the code holds your link directly.
  3. If it’s a QR provider’s short domain, it’s a redirect, and it only keeps working as long as that account does.

FAQ

Do QR codes expire?

The code itself never expires. Dynamic codes can stop working when the service behind them stops redirecting, for example after a free trial. Static codes keep working as long as the link inside them does.

What is the difference between a static and a dynamic QR code?

A static code stores your link directly. A dynamic code stores a short link on a provider’s server that forwards to your link, so it can be edited but depends on that provider.

Are ForeverQR codes really free forever?

Yes. They are static codes made in your browser, with no signup, watermark or trial. There is no server in between that could be switched off.

Can I change a static QR code after printing?

Not the code, but you can change the page it points to. Use an address you control and update that page.
