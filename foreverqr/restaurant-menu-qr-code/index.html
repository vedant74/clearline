A restaurant menu QR code that won’t expire on you

The worst time to learn your menu code was on a free trial is a busy Friday night. Here’s how to set one up once, keep the menu up to date, and never reprint because of the code.

Opens the generator set to a website link with the caption “Scan to see our menu”. Paste your menu’s address and download a table sign.

Make a menu QR code

The one decision that matters: what address goes in the code

A static QR code holds one web address forever. That sounds rigid, but it’s exactly what you want if the address is one you control. The trick is to put a stable address in the code and change what’s on the page behind it:

  • Best: a menu page on your own website, such as yourrestaurant.com/menu. Edit the page when prices change and every printed code shows the new menu instantly.
  • Fine: a PDF in cloud storage. If you use Google Drive, replace the file with Manage versions → Upload new version instead of uploading a new file, so the shared link stays the same. Uploading a fresh file creates a new link and strands your printed codes.
  • Avoid: a link that belongs to a trial or a third-party redirect. “Dynamic” QR codes point to the generator’s short link. Some providers deactivate those codes when a free trial ends, and the codes then show a service page instead of your menu.

This gives you what people pay a monthly fee for (the ability to change the menu without reprinting) with nothing to renew.

Step by step

  1. Publish the menu at its permanent address and open it on your own phone. Check that it loads quickly on mobile data and is readable without zooming.
  2. Open the generator with the button above and paste the full address, starting with https://.
  3. Check the preview. The line under the code shows exactly what it encodes. Scan it from the screen with two different phones.
  4. Download a sign (“Printable sign”) for table tents and the window, or the SVG for your designer or print shop.
  5. Test a printed proof in the real spot, under your real lighting, before you print the full run.

What size to print

The usual rule of thumb is that people can scan from about 10 times the code’s width away, and codes under 2 cm (0.8 in) cause trouble. In practice:

WhereTypical distanceCode width
Table tent or menu card30–50 cm3–5 cm (1.2–2 in)
Counter or bar signabout 1 m10 cm (4 in)
Front window or door1.5–2 m15–20 cm (6–8 in)

Tips from the floor

  • Matte, not glossy. Glossy lamination reflects overhead lights straight into the camera. Matte laminate or a plastic stand with a matte insert scans far more reliably.
  • Make the page fast. A 20 MB PDF on a weak signal feels broken. Compress images or use a simple web page.
  • Keep a few paper menus. Not everyone has a phone, a charged battery or good eyesight for a small screen.
  • Add your Wi-Fi. If reception is poor inside, a second Wi-Fi QR code on the same table card helps the menu load.
  • Check your old codes. Use the scanner on a printed code: if the link starts with a generator’s domain instead of yours, it’s a redirect you don’t control.

FAQ

Can I change the menu without reprinting the QR code?

Yes, if the code points to an address you control. Update the page (or replace the PDF using the same link) and every printed code shows the new menu.

Should my menu be a PDF or a web page?

A simple web page loads faster and reads better on phones. A PDF is fine if it is small and you replace it without changing its link.

What size should a QR code be on a table tent?

About 3–5 cm (1.2–2 in) wide. A common rule of thumb is a scanning distance of roughly 10 times the code width, and 2 cm is a practical minimum.

Will my menu QR code stop working?

A static code made here can’t expire because there is no redirect behind it. It works as long as the web address in it keeps working.
