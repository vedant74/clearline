Why did my QR code stop working?

A printed code that suddenly opens an “inactive” page, an error, or nothing at all can almost always be traced to one of four causes. Here’s how to find which one, and what to do about it.

Scan the problem code with the ForeverQR scanner. It shows the full content and the real destination, and never opens anything until you tap.

Check the code in the scanner

Step 1: See what’s actually inside the code

Scan it with the scanner (camera or a photo). The result tells you which branch you’re on:

  • A QR provider’s short link that opens an “inactive”, “expired” or “upgrade” page → go to cause 1.
  • Your own website, but the page shows an error → cause 2.
  • Wi-Fi details that no longer connect → cause 3.
  • Nothing scans at all → cause 4.

Cause 1: A dynamic code was deactivated

Many generators create dynamic codes by default: the code holds the provider’s short link, which forwards to your site. If the subscription or trial behind it ends, the provider may stop forwarding. For example, QR Code Generator’s help centre says its dynamic codes are deactivated when a free trial ends and point to a service page, and that upgrading to a paid plan reactivates them. Your options:

  • Reactivate with the original provider. Only the account that created the code can turn the redirect back on. No other website can fix an already-printed redirect code.
  • Replace it with a static code. Make a static code with your real link, and reprint or sticker over the old one. It can’t be deactivated again because there is no redirect.

If you can still log in to the old account, check whether it lets you change where the code points or shows the original destination, so you know exactly which link to put in the replacement.

Cause 2: The web page moved

If the code holds your own address and the page is gone, the fix is on your website, not the code: restore the page at the old address, or set up a redirect from the old address to the new one. Every printed code starts working again without reprinting. A common culprit is a menu PDF replaced by a new upload, which gets a new link; replace the file in place instead.

Cause 3: The Wi-Fi password changed

A Wi-Fi QR code contains the password itself. After a password change it needs to be remade; there’s no way around it.

Cause 4: Phones can’t read it

  • Too small for the distance. A common rule of thumb is about 10:1 distance to width, with about 2 cm as a practical minimum.
  • Glare from glossy lamination, foil or a shop window. Tilt the phone; if that fixes it, reprint on matte.
  • Low contrast or inverted colours. Light code on dark backgrounds fails on many phones. Use a dark code on a light background.
  • Missing margin. The code needs a clear border, four modules wide, on every side. Designers sometimes crop it.
  • Damage or fading on outdoor signs, or a code that’s too dense because the link is very long.

Replacing printed codes

  1. Make the new static code and test it from your screen with two phones.
  2. Print stickers at least as large as the old code, and cover it completely, so a phone can’t pick up a corner of the old one.
  3. Scan every replaced sign once. Then check them occasionally, especially outdoors.

FAQ

Why does my QR code say it is inactive or expired?

It is probably a dynamic code whose provider stopped redirecting, often after a free trial or subscription ended. Only that provider can reactivate it; otherwise replace it with a static code.

Can I fix a printed dynamic QR code without paying?

Not the printed code itself, because the redirect lives in the provider’s account. You can make a free static code with your real link and sticker over the old one.

My QR code opens an error page on my own website. What do I do?

Restore the page at its old address or add a redirect from the old address to the new one. The printed codes will work again without reprinting.

Why won’t my QR code scan at all?

Usually it is too small for the distance, has glare, has low contrast or inverted colours, or the margin around it was cropped. Reprint larger, matte, dark on light, with a clear border.

How do I stop this happening again?

Use static codes that hold your link directly, and point them at addresses you control so you can update the page instead of the code.
