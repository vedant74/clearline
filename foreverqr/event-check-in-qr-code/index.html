Event check-in with a QR code

For a meetup, class, workshop or open day, one QR code at the door that opens a short sign-in form replaces the clipboard, and gives you a clean attendee list afterwards.

Opens the generator set to a website link with the caption “Scan to check in”. Paste your sign-in form’s address.

Make a check-in QR code

Pick the right model first

One shared code (self check-in)

Everyone scans the same code, which opens a short form: name, email, maybe a tick box for consent to follow-up emails. Form tools such as Google Forms or Microsoft Forms record a timestamp with each response, so the response list doubles as your attendance record. This is free, takes ten minutes to set up, and works with a static code that will never expire, so you can reuse the same sign for every session of a weekly class.

Good for: free events, classes, meetups, conferences’ session attendance, open days, volunteer shifts.

One code per attendee (tickets)

If you need to stop people without tickets getting in, each attendee needs their own unique code, and staff need an app that checks each scan against the guest list and flags duplicates. That is what ticketing platforms provide. A plain QR generator can make a code containing a ticket ID, but it can’t tell you whether that ticket was already used.

Good for: paid events, capacity-limited venues, anything where entry must be controlled.

Set up self check-in, step by step

  1. Create the form. Keep it to three questions or fewer; every extra field slows the queue. Make it accept responses without the attendee signing in, if your tool allows.
  2. Copy the form’s share link and open it on a phone that isn’t logged in to your account, to see what attendees will see.
  3. Make the code with the button above. The caption “Scan to check in” is already set.
  4. Download the printable sign and print a few copies: one at the door, one on the registration table, one inside for latecomers.
  5. Test on the day with the venue’s mobile reception. If it’s weak, add a Wi-Fi QR code next to the check-in sign.

Sizing the door sign

A common rule of thumb is a scanning distance of about 10 times the code’s width. People in a queue will be 1–2 metres from a door sign, so print the code 10–20 cm (4–8 in) wide. On a registration table, 5 cm is plenty. Several smaller signs spread out beat one big sign that everyone crowds around.

More codes that help at events

  • Schedule or slides: a link to the agenda or the speaker’s slides on a sign by the stage.
  • Feedback form at the exit, with a different caption (“Tell us how it went”).
  • Name badges: a small contact QR code on each badge lets attendees swap details by scanning.

Don’t forget

  • Have a fallback. A paper list and a pen for people without a phone or battery.
  • Privacy. You are collecting personal data. Say what it’s for on the form and only ask for what you need.
  • Close the form after the event if it shouldn’t take more responses, or keep it open if the sign is reused next week.

FAQ

Can I use a free QR code for event check-in?

Yes, for self check-in. Make a static code that opens a short sign-in form; the form’s responses, with timestamps, become your attendance list.

Do I need a unique QR code for each attendee?

Only if you must control entry. Unique ticket codes need an app that checks each scan against the guest list, which ticketing platforms provide.

How big should the check-in QR code be?

About 10–20 cm (4–8 in) wide on a door sign read from 1–2 metres, and about 5 cm on a registration table.

Can I reuse the same check-in code every week?

Yes. A static code never expires, so the same sign works for every session as long as the form stays open.
