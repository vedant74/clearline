QR codes on product packaging

Packaging gets printed by the thousand and then sits in warehouses, on shelves and in people’s cupboards for years. A QR code on it has to keep working for that whole time. If it goes through a QR company’s redirect and the subscription lapses, every box you’ve already sold points at an error page, and the only fix is a reprint.

Make a packaging QR code

Static, not dynamic

A static code stores your web address in the black-and-white pattern itself. Any phone camera reads it straight to your site, with no server in the middle, so nothing can expire. Many “free” generators make dynamic codes by default instead: the pattern holds the company’s short link, and they forward scans to you only while your account is active. That’s fine for a poster that comes down next month. On packaging it’s a liability. Every code ForeverQR makes is static, and there’s no account to cancel.

Not sure what an existing pack uses? Scan it and look at the address your phone shows before it opens the page. If it’s the generator’s domain rather than yours, it’s dynamic. How to check a code has more detail.

Link to an address you control

The one catch with a static code is that you can’t change the address after printing. So don’t encode a long, fragile URL like a store’s product page or a file-sharing link. Use a short path on your own domain:

  • One per product: yourbrand.com/p/cold-brew for instructions, ingredients, refills or a how-to video.
  • One for the whole range: yourbrand.com/scan if a single code will go on every box.

Most website builders and hosts let you set up a redirect from a path like that to any page. Later you can point it somewhere new, such as a new shop or an updated manual, without touching the printed code and without paying anyone per scan. Just keep the domain renewed: it’s now part of your packaging.

Short addresses also help the print. A shorter link makes a code with fewer, larger squares, which scans more easily at small sizes.

To see how many people scan, add campaign tags before you make the code, for example yourbrand.com/p/cold-brew?utm_source=pack&utm_medium=qr. The visits show up in your own analytics. If you use tags, the redirect has to keep them, so test that.

Size, margin and contrast

SurfaceSuggested minimum width
Flat box or label, smooth stock2 cm (0.8 in)
Round bottle, jar or can2 cm, on the flattest part of the label
Kraft, corrugated or textured boardLarger: ink spreads into rough material

Packaging-print guides put the floor for consumer packs around 1–2 cm. 2 cm leaves room for small print errors and older phones. Those figures assume a short link, so a long URL needs more space.

  • Keep the quiet zone. Leave a clear border about four squares wide on every side. The generator’s margin setting defaults to 4. Don’t let the designer crop it or butt the code against a fold or panel edge.
  • Dark on light. More phones read a dark code on a light background than the reverse. On a clear label, print a white box behind the code. The generator warns you when contrast is weak.
  • Avoid seams, folds and wraps. A code across a box flap, a label overlap or a shrink-wrap seam will often fail. On a bottle, put it where the curve is gentlest and keep it small enough that the whole code faces the camera.
  • Matte beats gloss. Gloss lamination and foil can reflect store lighting straight into the camera.
  • Error correction: Medium suits most packs. Choose High if the code may get scuffed or carries a logo (the generator switches to High when you add one). Higher levels add squares, so give the code a little more room.

This isn’t the checkout barcode

You may have heard about GS1’s “Sunrise 2027”. It’s an industry push for stores to scan 2D codes at checkout by the end of 2027. Those are QR codes built to GS1 standards (GS1 Digital Link) that carry your product’s GS1 identifier. GS1 and packaging suppliers are clear that it isn’t a legal mandate, and that the 2D codes will sit alongside UPC and EAN barcodes rather than replace them right away. ForeverQR makes plain QR codes that send customers to a web page. Keep your existing barcode for the till. If your retailers ask for GS1 QR codes, get them through your GS1 member organisation.

FAQ

How small can a QR code be on packaging?

About 2 cm (0.8 in) wide is a safe minimum for a short link on a flat pack. Go bigger on curved bottles, kraft board or textured stock, and always test a printed proof.

Will a free QR code on my packaging stop working?

A static code won’t, because the address is stored in the pattern itself. Codes from many free generators are dynamic: they go through the company’s short link and can stop when a trial or subscription ends.

Can I change where a packaging QR code goes after printing?

Not the code itself, but you can point it at a page or redirect on your own domain and change that page whenever you like, without paying a QR service.

Can a QR code replace the barcode on my product?

Not a plain one. Checkout-ready QR codes use GS1 standards and carry your product’s GS1 number. Keep your UPC or EAN barcode; a ForeverQR code is for customers, not the till.
