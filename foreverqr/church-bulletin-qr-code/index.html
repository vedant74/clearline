QR codes for church bulletins

A bulletin is printed every week, usually from the same template. Once a QR code goes into that template it gets copied into every issue, plus the Christmas program, the welcome card and the lobby sign. So the code has to keep working for years. If it goes through a QR company’s redirect and the free trial or plan ends, every copy stops working at once, and you may not hear about it until someone mentions it after the service.

Make a bulletin QR code

Use a static code

A static code stores your web address in the pattern itself. A phone camera reads it and goes straight to your site, with no QR company in between, so nothing can expire. Many “free” generators make dynamic codes instead: the pattern holds their short link, and scans only reach you while your account is active. Every code ForeverQR makes is static, and there’s no account.

Already have a code in your template? Scan it and look at the address your phone shows before it opens. If it’s the generator’s domain rather than your church’s, it’s dynamic. Why did my QR code stop working? explains how to replace one.

One code, one page you update

You can’t change where a static code points after printing, and you don’t need to. Make a single page on your church website, for example yourchurch.org/connect or yourchurch.org/sunday, and point the code there. Then each week, change the page, not the code:

  • Give: a button to your existing online giving page. Use its permanent public address, not a link to one special appeal.
  • This week: sign-ups, the prayer request form, volunteer slots, the meal train, the youth group trip.
  • Watch: the livestream link (see below) and last week’s sermon.
  • New here? A short connect card form. A free form such as Google Forms works; the event check-in guide shows the setup.

One code is easier to scan than five codes crowded onto a half-page, and the person who edits the bulletin doesn’t have to remake anything. The same code can go on the Advent and Christmas programs, the welcome card and the visitor table, so everyone lands on the same up-to-date page.

If only one volunteer can edit the website, ask them to set up the page once; after that, swapping a few links each week is a small job that can be shared. Avoid pointing it at a single Google Doc or a file-sharing link that someone might delete or lock when they step down.

A livestream link that doesn’t change

If you stream to YouTube, you don’t need a new link every week. An address in the form youtube.com/channel/YOUR-CHANNEL-ID/live opens whatever is live on your channel right now. If one stream is scheduled, it shows that stream’s waiting page. If nothing is scheduled or several are, it falls back to your channel’s Live tab. It only works for public streams, so unlisted or private streams won’t show. Test it on a Sunday morning before you print it, and if you’d rather keep the bulletin flexible, put this link on your connect page instead of in its own code.

Guest Wi-Fi

A Wi-Fi QR code on a sign in the lobby or fellowship hall lets visitors join without asking for the password. Use your guest network, not the office one. If you ever change the password, the Wi-Fi code has to be reprinted, which is one more reason to keep it on a sign rather than in the weekly bulletin.

Size and print

WhereSuggested width
Bulletin, laser-printedAt least 2 cm (0.8 in)
Bulletin, photocopied or on a duplicatorAbout 2.5 cm (1 in) or more
Sign on the welcome table, read from 1 mAbout 10 cm (4 in)

Those sizes come from the common rule of thumb that a code scans from about ten times its own width, with 2 cm as a practical minimum for something held in the hand. The generator’s printable sign (6 × 8 in) is a good size for the welcome table.

  • Keep the white border. Leave a clear margin about four squares wide on every side. Don’t let the code run into a clip-art border or the page edge.
  • Stay off the fold. A code across the centre crease of a folded bulletin often won’t scan. Put it on the back panel or an inside page, away from the fold.
  • Black on white or light paper. Coloured paper is fine if it’s pale. Dark card stock or a dark ink colour makes it harder to read.
  • Copiers soften edges. Print the master from the SVG or PNG file, not a copy of an old bulletin, and choose High error correction if the copies come out grey or speckled.
  • Tell people what it’s for. A line beside the code, like “Scan to give, sign up or watch online”, gets more scans than a bare code.

What about the screen?

A code on the announcement slides only works for people near the front. By the same ten-to-one rule, someone 15 m (50 ft) back would need the code to appear about 1.5 m (5 ft) wide. If you show it on screen, make it large, leave it up for a while, and say that the same code is in the bulletin.

Step by step

  1. Make the connect page on your website, with giving, this week’s sign-ups and the livestream link.
  2. Open the generator with the button above and paste the page’s full address.
  3. Scan the on-screen preview with a phone to check it opens the right page.
  4. Download the SVG or high-resolution PNG and place it in your bulletin template.
  5. Print one copy the way you’ll print the real run (including the copier) and test it with an iPhone and an Android phone.
  6. From then on, update the page each week. Leave the code alone.

FAQ

Will a free QR code in our bulletin stop working?

A static code won’t, because the address is stored in the pattern itself. Many free generators make dynamic codes that go through their own short link, and those can stop when a trial or plan ends, which breaks every bulletin that used it.

Do we need a new QR code every week?

No. Point one code at a page on your church website, such as yourchurch.org/connect, and update that page each week. The printed code stays the same in your bulletin template.

How big should a QR code be in a bulletin?

At least 2 cm (0.8 in) wide, and about 2.5 cm (1 in) if the bulletin is photocopied. Keep a clear white border around it and keep it off the fold.

Can a QR code link to our YouTube livestream every week?

Yes, if the stream is public. A link of the form youtube.com/channel/YOUR-CHANNEL-ID/live opens the current or scheduled stream, and falls back to the channel’s Live tab when there isn’t one.
